# decc-crtl-names.txt -- every C RTL entry-point name the alpha-dec-vms GCC port
# binds through its CRTL name map (vms-fe03).
#
# The port compiler decorates exactly these names (decc$<name>, decc$_<name>64,
# decc$t<name>, ...); any other function a client calls is referenced by its bare
# name, which DECC$SHR does not export. So the OVMX C RTL headers declare, for
# alpha-dec-vms clients, only functions named here (plus the RTL's own __ names
# and the threads headers, see build-musl.sh): a configure probe on OVMX then
# sees the same RTL a configure on OpenVMS does, instead of a declaration whose
# definition no link can reach.
#
# Enumerated from the GPL gcc/config/vms/vms-crtlmap.map of GCC 14.2.0 (names
# only -- public C RTL entry-point names are facts; no flags, no other content),
# as src/vmslink/decc_crtl_map.txt is. One name per line.
